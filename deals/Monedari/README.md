# Deal template

The folder structure every deal uses. To start a new company, copy this whole `_TEMPLATE` folder and rename the copy to the company name.

Put the pitch deck in `_inbox/deck/` and the first-call notes in `_inbox/pre-ic-calls/`. Each numbered folder then receives the output of one stage.

| Folder | What lands here |
|---|---|
| `_inbox/` | Raw inputs: the pitch deck and the first-call notes |
| `0-prescreen/` | Pre-screen for the weekly screening committee |
| `1-impact/` | Impact template |
| `2-preic/` | Pre-IC scorecard and investment template |
| `3-ic-feedback/` | Investment committee (IC) discussion notes, then the IC feedback and due-diligence guide |
| `4-dd/` | Due diligence, in six sub-folders (see its own README) |
| `5-final-scorecard/` | Final scorecard, after due diligence |
| `6-ic-memo/` | IC memo: the deck and its annex |

The `.gitkeep` files only keep the empty folders in git. The agents ignore them.
